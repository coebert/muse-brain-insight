# MindGuard EEG source search, 21 November 2026

The [clinical source catalogue](../eeg/source-catalogue.csv) now has 256 entries. Rows EEG-239 to EEG-256 are the 18 additions from this search. Four are published studies for which a public release of raw recordings could not be verified. The other additions cover public archives, research-use and provider-listed recordings, and one explicitly preprocessed waveform collection.

The [repository index](eeg-repository-index.csv) lists 843 EEG or intracranial EEG accessions. Each row links to its provider. Where available it also records a concrete example waveform path. It includes 532 OpenNeuro accessions and 311 NEMAR-native accessions. A catalogue entry can cover several releases, while an archive index can include several copies or tasks from one participant cohort. The counts describe different things and cannot be added to obtain a cohort count.

## Coverage and verification

The [repository sweep](repository_sweep.py) reads a [pinned EEGDash listing](https://github.com/EEGDash/EEGDash/blob/aa9ce696e9a01c087fef325ddeea542835987e97/eegdash/dataset/dataset_summary.csv) and the [live EEGDash metadata API](https://data.eegdash.org/api/eegdash/datasets/summary). This run read 751 pinned rows and 954 live rows. OpenNeuro and NEMAR mirror IDs were collapsed when they encode the same accession. The Healthy Brain Network competition subsets were mapped to their parent releases. Portals searched separately included DANDI, Zenodo, PhysioNet, Donders, Chinese university and national repositories, and literature linked to regional clinical studies. Dataset-specific rights are recorded in the clinical catalogue where checked.

The file check sampled up to the first 300 OpenNeuro S3 keys under the accession-wide `sub-` prefix, or searched a NEMAR Git file tree. It accepted signal-bearing EDF, BDF, BrainVision EEG, EEGLAB FDT or SET, CNT and NWB filenames in subject EEG/iEEG directories. Sidecars alone did not qualify. SET can require an accompanying FDT. The check did not fetch recording bytes, measure signal quality, validate the complete companion files, or enumerate all hours. Negative or inaccessible listings are retained for further investigation. NEMAR Git trees commonly contain annex pointers. Use the provider to fetch data.

The last three index columns enrich the [machine-generated listing](https://github.com/coebert/muse-brain-insight/actions/runs/44917811661) with catalogue references, the basis for each link, and signal-review notes. 118 rows have a reference to the previous 238-entry catalogue. After adding this search's clinical entries, 129 rows have a recorded link and 714 have no recorded match. Matching used accessions, identified DOIs and named source families. A linked family may contain distinct participants. An unmatched release may still repackage previously indexed people or recordings. The underlying snapshot, licence strings, reported participant counts and record counts are provider metadata. Record counts can represent files, and repository metadata can disagree with the original study. The population and signal-review fields are screening hints based on titles. Some entries contain animal, phantom, converted, preprocessed or invasive signals.

For model development, record the source release, original cohort ID, signed terms where applicable, recording and participant identifiers, device, reference, channel locations, sample rate, physical units, medication exposure and how labels were obtained. Group repeats and mirrored versions before assigning patients to splits. Use electrode pairs available on the proposed device for the main evaluation. Keep an external hospital or device cohort held out and report performance against its actual clinical endpoint. This search populated the research inventory. It did not analyse patient waveforms or train a model.
