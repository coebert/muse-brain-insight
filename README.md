# MindGuard AI

I want to create a new app that will use the Muse 2 EEG headband to extract information/data from patients under general anaesthesia and patients sedated on ICU. I want the app to be able to take data from the Muse 2 device and generate a direct spectral array. I also want the app to detect burst suppression, and to be able to provide suppression ratio and a suppression time. I want the app to be able to save anonymised data for each patient it is used for. I want the app to be able to use the extracted information to detect potential seizure activity
